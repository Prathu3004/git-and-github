# Simple Interest Calculator

A simple, clean, and beginner-friendly web application designed to calculate Simple Interest and Total Amount accurately based on user inputs for Principal, Interest Rate, and Time.

---

## 📌 Purpose of the Project

The purpose of this project is to provide an intuitive financial tool that allows users to quickly calculate the total interest earned or owed over a given period of time. It demonstrates fundamental web development practices using HTML, CSS, and Vanilla JavaScript with robust input validation and modern responsive UI styling.

---

## 📐 Mathematical Formulas

### 1. Simple Interest Formula
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

### 2. Total Amount Formula
$$\text{Total Amount} = \text{Principal} + \text{Simple Interest}$$

*Where:*
- **Principal ($P$)**: Initial amount of money invested or borrowed.
- **Rate ($R$)**: Annual interest rate (in percentage %).
- **Time ($T$)**: Duration for which the money is invested or borrowed (in years).

- 💡 **Simple & Intuitive Interface**: Clean, clutter-free user interface.

## 🚀 How to Run the Project

Since this project uses pure HTML, CSS, and JavaScript, no server installation or build tools are required!

### Option 1: Open Directly in Browser
1. Clone or download the repository to your local computer:
   ```bash
   git clone https://github.com/Prathu3004/git-and-github.git
   ```
2. Navigate into the project folder:
   ```bash
   cd git-and-github
   ```
3. Double-click `index.html` or open it in your web browser (Chrome, Firefox, Edge, Safari).

### Option 2: Run via VS Code Live Server
1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **"Open with Live Server"**.
